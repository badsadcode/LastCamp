# Last Camp Protocol - GDD Pack

This pack contains markdown documents for an HTML5 survival camp management game.

## Files

- `01_Last_Camp_Protocol_GDD.md` - Full game design document.
- `02_AI_Implementation_Steps.md` - Chunked build plan for AI-assisted development.
- `03_First_Coding_Prompt.md` - First practical prompt to give Codex or another coding AI.

## Suggested Use

Start with the GDD to understand the game vision, then follow the implementation steps one chunk at a time. Do not skip ahead too much or the feature-creep goblin will crawl out of the basement.
